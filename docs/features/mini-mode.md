# Mini mode

Mini mode is a compact panel that shows your active sessions in a narrow sidebar, useful when you want to keep an eye on session activity without the full dashboard taking up screen space.

## Toggling mini mode

From the CLI:

```bash
weaver toggle
```

From the tray menu: click the tray icon and toggle **Mini Mode**.

## Behavior

- The window shrinks to a narrow panel (300px wide)
- Shows a list of active sessions with their current status
- The panel auto-resizes to fit the number of sessions
- Click a session to open it in the full dashboard

Toggle again to return to the full dashboard view.
